VOXFLOW LIVE ZETTEN OP AZURE — STAP VOOR STAP

Volg de stappen van boven naar beneden.

Wat je gaat doen:
1) Bij elke dienst de juiste sleutel ophalen
2) De backend op Azure zetten
3) Alle sleutels in Azure invullen (environment variables)
4) De server in dev-modus zetten
5) De frontend (Lovable) koppelen aan de backend

Maak een leeg kladblok. Plak elke sleutel er meteen in. In DEEL 3 plak je ze in Azure.


==============================
DEEL 1 — SLEUTELS OPHALEN
==============================


1.1 SUPABASE (database + inloggen)
- Ga naar supabase.com, log in, open het project.
- Project Settings (tandwiel) > Data API (of API): kopieer de Project URL (https://xxxx.supabase.co).
  >> Bewaren als: Supabase__ProjectUrl
- Project Settings > API: kopieer de "anon public" key (heb je nodig in DEEL 4 voor de frontend).
- Database > Connection string > kies het tab "Transaction pooler" (NIET "Direct connection").
- Kies het formaat .NET als dat er staat, anders URI.
- Vervang [YOUR-PASSWORD] door het database-wachtwoord. Wachtwoord kwijt? Klik op dezelfde pagina op Reset database password.
- Kopieer de volledige string.
  >> Bewaren als: ConnectionStrings__DefaultConnection
- De SQL-query voor de tabellen krijg je apart. Plak die in Supabase > SQL Editor > New query > Run.


1.2 GOOGLE CLOUD / GEMINI
- Ga naar console.cloud.google.com, log in, kies of maak een project.
- Klik bovenin op de projectnaam en kopieer de Project ID (kleine letters, bv voxflow-123456).
  >> Bewaren als: Gemini__ProjectId
- Zoek bovenin naar "Vertex AI API", open het, klik Enable.
- IAM & Admin > Service Accounts > Create service account. Naam: voxflow-vertex. Rol: Vertex AI User. Klik Done.
- Klik op die service account > tab Keys > Add key > Create new key > JSON > Create. Er wordt een .json bestand gedownload.
- Open het .json bestand met Kladblok en kopieer de HELE inhoud (alles van { tot }).
  >> Bewaren als: Gemini__ServiceAccountKeyJson


1.3 DEEPGRAM
- Ga naar console.deepgram.com, log in.
- API Keys > Create a New API Key. Naam: voxflow. Rechten standaard laten. Create.
- Kopieer de sleutel meteen.
  >> Bewaren als: Deepgram__ApiKey


1.4 ELEVENLABS (de stem)
- Ga naar elevenlabs.io, log in.
- Profielicoon rechtsboven > API Keys > Create API Key. Naam: voxflow. Rechten standaard. Create.
  >> Bewaren als: ElevenLabs__ApiKey
- De stem wordt per bedrijf in het dashboard ingesteld. Geen Voice ID nodig hier.


1.5 TWILIO (bellen + WhatsApp)
- Ga naar console.twilio.com, log in.
- Op het hoofd-dashboard staan meteen:
  - Account SID  >> Bewaren als: Twilio__AccountSid
  - Auth Token (klik Show/Reveal)  >> Bewaren als: Twilio__AuthToken
- (Optioneel, alleen als klanten in de app zelf een nummer kopen) Account (rechtsboven) > API keys & tokens > Create API key. Naam: voxflow. Type: Standard. Create. Kopieer SID en Secret meteen (Secret zie je maar 1 keer).
  >> Bewaren als: Twilio__ApiKeySid en Twilio__ApiKeySecret
- Telefoonnummer koppelen (doe dit als je het Azure-adres uit DEEL 2 weet):
  Phone Numbers > Manage > Active numbers > klik het nummer.
  - Voice Configuration > "A call comes in" > Webhook > https://JOUW-AZURE-ADRES/api/twilio/answer > HTTP POST
  - Call status changes > https://JOUW-AZURE-ADRES/api/twilio/status > HTTP POST
  - Save
- WhatsApp (optioneel): Messaging > Senders > WhatsApp senders. Nummer in de vorm whatsapp:+31...
  >> Bewaren als: Twilio__WhatsAppFrom (anders leeg laten)
- SMS-verificatie (optioneel): Verify > Services > kopieer Service SID (VS...).
  >> Bewaren als: Twilio__VerifyServiceSid (anders leeg laten)


1.6 GMAIL (bevestigingsmails)
- Log in op het Google-account dat de mails verstuurt.
- myaccount.google.com/security > zet 2-stapsverificatie AAN.
- myaccount.google.com/apppasswords > app-naam VoxFlow > Create. Kopieer de 16 letters ZONDER de spaties.
  >> Bewaren als: Gmail__AppPassword
- Het e-mailadres zelf (bv info@voxflow.nl)
  >> Bewaren als: Gmail__SenderEmail


1.7 OUTLOOK-AGENDA (optioneel)
- portal.azure.com > zoek "App registrations" > New registration. Naam: VoxFlow Outlook. Redirect URI: type Web + https://JOUW-AZURE-ADRES/api/integrations/outlook/callback > Register.
- Kopieer Application (client) ID.
  >> Bewaren als: Outlook__ClientId
- Certificates & secrets > New client secret > Add. Kopieer de Value meteen.
  >> Bewaren als: Outlook__ClientSecret
- API permissions > Add a permission > Microsoft Graph > Delegated permissions > vink aan: Calendars.ReadWrite, offline_access, User.Read > Add permissions.


1.8 ADMIN-INLOG (zelf kiezen)
- Verzin een gebruikersnaam  >> Admin__Username
- Verzin een sterk wachtwoord  >> Admin__Password


==============================
DEEL 2 — BACKEND OP AZURE ZETTEN
==============================

2.1 Bestaat de app al?
- portal.azure.com > zoek bovenin "App Services".
- Staat "VoxFlow" in de lijst? Ga door naar DEEL 3.
- Niet? Maak hem aan met 2.2.

2.2 Nieuwe Web App aanmaken (alleen als hij niet bestaat)
- App Services > Create > Web App. Vul in:
  - Resource group: bestaande of nieuwe (voxflow-rg)
  - Name: voxflow
  - Publish: Code
  - Runtime stack: .NET 10 (of de nieuwste .NET)
  - Operating System: Linux
  - Region: West Europe
  - Pricing plan: Basic B1
- Review + create > Create.

2.3 Automatisch deployen vanuit GitHub
- Open de Web App > Deployment Center.
- Source: GitHub > log in > autoriseer.
- Kies organisatie, repository (aicallassistent) en Branch: Master.
- Build provider: GitHub Actions > Save.

2.4 WEB SOCKETS AAN ZETTEN (VERPLICHT)
- Web App > Settings > Configuration > tab General settings (of Platform settings).
- Web sockets > On.
- Always on > On.
- Save bovenaan.


==============================
DEEL 3 — SLEUTELS INVULLEN IN AZURE
==============================

3.1 Waar?
- Web App VoxFlow > Settings > Environment variables.
- Onder App settings klik je telkens op "+ Add".
- Bij Name de naam (bv Deepgram__ApiKey), bij Value jouw sleutel.
- Het zijn twee liggende streepjes __ , geen dubbele punt.
- Onderaan klikken op Apply/Save en bevestigen. Sleutels werken pas na de herstart.

3.2 VERPLICHT — deze MOET je invullen (Naam = jouw waarde)

ASPNETCORE_ENVIRONMENT = Development
ConnectionStrings__DefaultConnection = JOUW_SUPABASE_CONNECTION_STRING
Supabase__ProjectUrl = https://xxxx.supabase.co
Gemini__ProjectId = JOUW_GOOGLE_PROJECT_ID
Gemini__ServiceAccountKeyJson = PLAK_HIER_DE_HELE_JSON
Deepgram__ApiKey = JOUW_DEEPGRAM_KEY
ElevenLabs__ApiKey = JOUW_ELEVENLABS_KEY
Twilio__AccountSid = JOUW_TWILIO_ACCOUNT_SID
Twilio__AuthToken = JOUW_TWILIO_AUTH_TOKEN
Twilio__BaseUrl = https://JOUW-AZURE-ADRES
Cors__AllowedOrigins__0 = https://FRONTEND-ADRES

- Twilio__BaseUrl moet exact het openbare Azure-adres zijn (met https://, zonder / aan het eind).
- CORS: ook een www- of *.lovable.app adres? Voeg toe als Cors__AllowedOrigins__1, Cors__AllowedOrigins__2, enz.


3.3 OPTIONEEL — alleen invullen als je die functie gebruikt

# Admin-paneel (inloggen op de admin):
Admin__Username = JOUW_ADMIN_GEBRUIKERSNAAM
Admin__Password = JOUW_STERKE_WACHTWOORD

# Bevestigingsmails:
Gmail__SenderEmail = info@voxflow.nl
Gmail__AppPassword = JOUW_16_LETTER_APP_WACHTWOORD

# Nummers kopen / onboarding in de app:
Twilio__ApiKeySid = JOUW_TWILIO_API_KEY_SID
Twilio__ApiKeySecret = JOUW_TWILIO_API_KEY_SECRET

# WhatsApp:
Twilio__WhatsAppFrom = whatsapp:+31...

# SMS-verificatie bij aanmelden:
Twilio__VerifyServiceSid = VS...

# Outlook-agenda koppelen:
Outlook__ClientId = JOUW_OUTLOOK_CLIENT_ID
Outlook__ClientSecret = JOUW_OUTLOOK_CLIENT_SECRET
Outlook__RedirectUri = https://JOUW-AZURE-ADRES/api/integrations/outlook/callback
Outlook__DashboardUrl = https://FRONTEND-ADRES/dashboard/integraties


3.4 NIET INVULLEN — dit zit al in de code

Deze hoef je NIET toe te voegen; er zitten al vaste waarden in, of ze komen per bedrijf uit de database (dashboard):
- Uit de database: de stem, taal, prompt, toon, begroeting, openingstijden, doorschakelnummers.
- Vaste waarde in de code: Gemini__Model, Gemini__Location, ElevenLabs__Model, ElevenLabs__Language, Deepgram__Model, Deepgram__SttProvider, Deepgram__BaseUrl, Assistant__DefaultCompanyId, Assistant__WelcomeMessage, Gmail__SenderName.

Klik na het invullen Apply/Save onderaan en laat de app herstarten.


==============================
DEEL 4 — FRONTEND (LOVABLE) KOPPELEN
==============================

4.1 In Lovable
- Open het project in Lovable.
- Zet de "API base URL" (vaak VITE_API_URL of VITE_API_BASE_URL) op het Azure-adres van de backend, bv: https://voxflow-xxxx.westeurope-01.azurewebsites.net
- Naam onbekend? Vraag in de Lovable-chat: "Welke environment variable gebruikt de app voor de backend-URL?"
- Vul in Lovable ook de Supabase Project URL + de anon public key in (uit DEEL 1.1).
- Publiceer de frontend en noteer het openbare adres (bv https://voxflow.nl of een *.lovable.app adres).

4.2 In Azure (CORS)
- Cors__AllowedOrigins__0 = het exacte frontend-adres, met https://, zonder / op het eind (bv https://voxflow.nl).
- Ook een www-variant of *.lovable.app adres? Voeg toe als Cors__AllowedOrigins__1, __2, enz.
- Apply/Save > app herstart.


==============================
DEEL 5 — CONTROLEREN
==============================

1) Open in de browser: https://JOUW-AZURE-ADRES/swagger — je hoort een testpagina met endpoints te zien.
2) Log in het dashboard in of open een lijst.
3) Doe een actie die gegevens ophaalt. Werkt het niet? Druk F12 > tab Console. Staat er "CORS"? Frontend-adres toevoegen bij Cors__AllowedOrigins. Staat er "401"? Inlog/token-probleem.
4) Bel het Twilio-nummer. Neemt hij niet op of valt weg? Controleer: Web sockets = On, Twilio__BaseUrl exact het Azure-adres, en de Twilio-webhook .../api/twilio/answer.
